# Maaltijdplanner

Een React applicatie voor het plannen van maaltijden en mealprep. Met deze applicatie kun je:
- Maaltijden toevoegen aan je plan
- Het aantal porties aanpassen
- Gedetailleerde instructies bekijken voor elke maaltijd
- Je maaltijdplan overzichtelijk beheren

## Installatie

1. Installeer de dependencies:
```bash
npm install
```

2. Start de ontwikkelserver:
```bash
npm start
```

De applicatie zal nu beschikbaar zijn op [http://localhost:3000](http://localhost:3000)

## Gebruik

1. Klik op "Maaltijd Toevoegen" om een nieuwe maaltijd toe te voegen aan je plan
2. Pas het aantal porties aan met de numerieke invoer onder elke maaltijd
3. Klik op het potlood-icoon om de gedetailleerde instructies van een maaltijd te bekijken

## Technologieën

- React
- TypeScript
- Material-UI
- Emotion (voor styling)
